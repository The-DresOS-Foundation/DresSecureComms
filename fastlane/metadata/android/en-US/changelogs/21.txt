Contacts can now hold more than one number each with its own type Mobile, Home, Work, Fax or Other. A new contact starts with a single number and you add more only if you want them, so there are no empty fields to scroll past. When someone has several numbers the app asks which to use for a message or call, and an incoming message or call from any of them now shows their name. Import and export keeps every number with its type. Thank you to the user who suggested this.

Fixes a crash on Android 16 when receiving an MMS: the bundled messaging library called a system method that newer Android has removed, so the app stopped the moment a picture message arrived. The app now handles that step itself and downloads the message as before. Thank you to the user who reported it on a Samsung Galaxy S24. The file scanner is also no longer labelled "coming soon" it has worked since 1.9.0.
